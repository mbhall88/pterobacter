# Pterobacter mascot

A pterodactyl inspecting a bacterium, made for Pterobacter at Michael Hall's request on 14 October 2026 using OpenAI image generation. The icon is a cartoon brand asset, not a biological illustration. The repository's MIT licence applies to this supplied asset.

Design brief: a playful winged pterodactyl with a long pointed beak and backward crest, thoughtfully inspecting a bacterial rod; bold flat shapes, readable at README size, no lettering and a transparent background. This is the first concept for author review.
